# ADR-0006: цена 0 у KP значит «цена не указана»

## Контекст и проблема
В живом прогоне (сухой прогон 19.11 с сербского IP) объявление «Macbook air A2179 delovi» пришло из JSON KP с ценой 0 RSD и дало ложное уведомление «ниже цели». KP так отдаёт объявления «Kontakt» / «Dogovor».

## Рассмотренные варианты
* считать 0 бесплатным (было)
* считать 0 неизвестной ценой, бесплатным только при явной отметке

## Решение
Цена 0 в JSON KP → цена не указана. Бесплатно (0.0) только при явной отметке: besplatno, poklanjam, gratis в тексте цены или заголовке, или флаг вроде isFree. В HTML карточке слово «бесплатно» в описании больше не перебивает настоящую цену.

### Последствия
* Хорошо: нет ложных «ниже цели».
* Плохо: настоящий подарок без явной отметки придёт как «цена не указана» (только уведомление о новом).

### Как проверяем
`tests/test_real_dryrun.py` (реальные объявления из прогона, полный проход без ложного «ниже цели»).
