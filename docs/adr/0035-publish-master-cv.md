# ADR-0035: полный master CV Лёни лежит в репо, `cv/master_cv.md`

## Контекст и проблема
Главная гипотеза вакансий H-35 меряет близость вакансии к опыту кандидата. До сих пор эталоном был публичный профиль навыков, а полное CV лежало только локально в `private/` (в gitignore), потому что репо публичное.

## Факторы решения
* репо публичное, всё в git истории остаётся навсегда
* полное CV нужно как эталон для H-35 и для ретрива
* данные Лёни, решает он

## Рассмотренные варианты
* репо в приват, CV как есть
* очищенное CV без контактов
* полное CV как есть в публичном репо

## Решение
Третий вариант. Лёню предупредили, что репо публичное и CV останется в истории гита. Он ответил (2026-11-20): «клади весь, в удобном md формате, самую полную версию, мне скрывать нечего». Это осознанное согласие на публикацию его собственных данных.
`cv/master_cv.md` собран из master резюме, ссылок из всех его PDF CV (аннотации URI) и проверенных публичных источников (доклады, статья Provectus про re:MARS 2022). Ни паролей, ни токенов, ни переписки в файле нет. `private/` остаётся в gitignore, ролевые PDF и `targets/de_jobs.local.json` по-прежнему не коммитим, `cv/` под gitignore и не попадал, правка `.gitignore` не понадобилась.

### Как проверяем
* перед push секрет скан проверки push
* EXP-010 вариант B берёт стек из `cv/master_cv.md`
