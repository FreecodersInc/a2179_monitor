# ADR-0028: позитив вакансий: SRE, DevOps, ML engineer да, Data Science отдельным вариантом

## Контекст и проблема
Метки de_jobs считали позитивом только Data Engineer и близкие (E), соседние роли шли в S или C. Gate профиля закрывал 67 из 207 позитивов, recall 1.0 был недостижим (EXP-006). Лёня 2026-11-20: SRE, DevOps, ML engineer это его опыт, значит позитив. Data Science попробовать как позитив.

## Факторы решения
* позитив должен совпадать с тем, на что кандидат реально подаётся
* gate и регекс профиля должны пускать все позитивы
* DS спорный, решаем по числам

## Рассмотренные варианты
* оставить определение
* расширить позитив и профиль, DS сразу в позитив
* расширить позитив и профиль, DS отдельным заранее заявленным вариантом

## Решение
Третий вариант. Профиль v2 (`targets/de_jobs.json`): модель `ml_sre_infra` и расширенный `strong_part`. 6 строк перемечены C → S, старая метка в `esci_v1`. DS считается через `eval/nested_cv.py --relabel-rx`, оба результата показываем. Профиль v2 писался после взгляда на пачку 2, поэтому числа на ней в его пользу. Честно только пачка 3 из невиденных строк (T-025).

### Как проверяем
EXP-009: gate закрывает 12 из 213, лучший канал F1 0.879, DS вариант 0.903. Пачка 3 (T-025)
