# ADR-0007: эмбеддер выключен в примере конфига, пороги TF-IDF 0.34/0.16

## Контекст и проблема
EXP-001 сравнил regex, TF-IDF, BM25, MiniLM, смеси и явные признаки на `eval/labeled.jsonl` (99 строк). Нужно выбрать, что монитор использует по умолчанию.

## Факторы решения
* лучший результат при recall 1.0
* прозрачность и меньше зависимостей
* устойчивость порогов (не на краю плато)

## Рассмотренные варианты
* hybrid regex + MiniLM (P 0.840, 8 FP, пороги 0.84/0.0, прогон Лёни)
* hybrid regex + TF-IDF 0.38/0.18 (P 0.977, 1 FP, край плато: шаг дальше теряет id 62)
* hybrid regex + TF-IDF 0.34/0.16 (те же P 0.977, R 1.000, середина плато)
* hybrid с BM25, RRF или отдельным слагаемым признаков (1 или 2 FP, без выигрыша)

## Решение
hybrid regex + TF-IDF, pos 0.34, margin 0.16 (по умолчанию в коде и в `config.example.json`). Эмбеддер в `config.example.json` выключен (`"enabled": "false"`), откалиброванные пороги Лёни 0.84/0.0 оставлены на случай включения.

### Последствия
* Хорошо: лучший результат на наборе без torch, запас 0.047 по pos и 0.039 по margin для строк вроде id 62.
* Плохо: набор маленький и наполовину синтетический, решение надо перепроверить на EXP-002.

### Как проверяем
`python eval/run_eval.py`, `python eval/sweep.py`, EXP-002 после пополнения набора.
