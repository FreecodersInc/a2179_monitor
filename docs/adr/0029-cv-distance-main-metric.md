# ADR-0029: главная метрика вакансий: близость к опыту кандидата, метки только линейка

## Контекст и проблема
Задача кейса вакансий не «DE или нет», а насколько вакансия близка к опыту кандидата (навыки, стек, домен, уровень), как спека экрана в A2179. Метки E/S/C/I ставились по заголовку и годятся только как проверка.

## Факторы решения
* скор объясним по частям
* веса не подбираются по меткам
* полное CV персональные данные, в репо не идёт

## Рассмотренные варианты
* классификатор по меткам
* скор близости к эталону из профиля навыков, метки проверяют
* скор по полному CV в репо

## Решение
Второй вариант. `eval/cv_distance.py`: `cv_score = 0.30 skills + 0.30 stack + 0.25 domain + 0.15 seniority`, части зафиксированы до прогона (EXP-010). Эталон одобренный профиль навыков `targets/de_jobs.json`. Полное CV только локально в `private/`, в репо и коде его нет, в отчётах только агрегаты. Метки проверяют скор (AUC, Spearman по степени, вложенная CV), но не настраивают его.

### Как проверяем
EXP-010: AUC 0.902, Spearman 0.776, F1 0.861 против 0.879 у признаков, H-35 держится. Дальше метки по полному тексту (T-032)
