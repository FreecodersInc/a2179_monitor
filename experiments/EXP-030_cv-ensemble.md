# EXP-030. Полный реестр эмбеддеров и ранжирование вакансий по CV

Запрос CI от 2026-11-21. Сравниваем ensemble с cv_score и TinyBERT по AUC (E/S против C/I) отдельно на labeled и batch3. Считаем улучшением превышение обоих одиночных каналов на обеих пачках. Метки в них ботские. Для текущей выдачи показываем оценки без утверждения о качестве. Долю новых вакансий считаем по URL относительно последнего опубликованного all.csv.

Обычный sweep считает модели на обоих исторических наборах. Для свежего отложенного набора экранов сохраняем pos/neg каждого эмбеддера, отдельно mMARCO на реальных лотах. У восьми новых лотов метки пользователя. Остальные метки сохраняют прежнее происхождение.

В vacancies.csv одна строка на вакансию. Dense сравнивает Professional Summary из cv/master_cv.md с заголовком по косинусу, TinyBERT использует запрос EXP-022. В labeled.csv и batch3.csv те же каналы. Ранги нормированы внутри каждой таблицы от 0 до 1, ничьи получают средний ранг. Итог равен сумме rank каждого канала, умноженного на коэффициент из weights.csv. Семейства cv_score, TinyBERT и dense имеют равные доли. В dense каждая доступная модель имеет равную долю, варианты префиксов E5 делят одну долю. Чтобы поменять приоритеты, используйте собственные коэффициенты с суммой 1. Ошибки загрузки и доступные каналы записываются в exp030.json. Веса моделей остаются в кэше раннера.
