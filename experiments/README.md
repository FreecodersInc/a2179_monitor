# Реестр экспериментов

Проект шире, чем один экран для старого MacBook: это площадка для исследований **сопоставления и поиска** (matching / retrieval). Как понять, что объявление, документ или карточка товара это именно то, что ищут, а не просто «про то же самое». Мониторинг A2179 здесь первый полигон с живыми данными и честной разметкой.

## Метод

Каждый эксперимент идёт по научному методу:
1. **Вопрос и гипотеза**, записанные *до* прогона. Что ожидаем увидеть и что будет считаться опровержением.
2. **Условия**: данные, код, параметры, окружение.
3. **Процедура**: точная команда, которую можно повторить.
4. **Результаты**: только числа из реального прогона или ссылки на артефакты. Чего не считали, так и пишем: «не прогонялось».
5. **Выводы**: что подтвердилось, что нет.
6. **Угрозы валидности**: размер выборки, синтетика, переобучение порогов, одна модель, утечки.
7. **Следующие шаги**.

Правила:
- **Один эксперимент = один файл** `experiments/EXP-NNN_<slug>.md` по шаблону [`TEMPLATE.md`](TEMPLATE.md) и свои артефакты в `reports/` (сырые логи в `reports/raw/`). Номера не переиспользуются, файл не удаляется, даже если гипотеза провалилась. Отрицательный результат тоже результат.
- **Воспроизводимость**: в записи всегда есть commit hash кода, версия данных (git blob и sha256 файла с данными), параметры, команда, seed (или «детерминировано», если случайности нет), окружение (ОС, Python, версии ключевых библиотек, CPU/GPU).
- **Данные меняются только новой версией**: дописали строки в набор, значит у набора новый hash, и старые числа относятся к старому hash.
- Решения, которые выросли из эксперимента, записываются как ADR в [`docs/adr/`](../docs/adr/README.md), задачи и планы в [`work/`](../work/README.md).
- **Никаких выдуманных чисел**: если цифра взята из чужого прогона (например, с другой машины), пишем откуда.

Снять отпечаток для записи:
```bash
git rev-parse HEAD                    # commit кода
git rev-parse HEAD:eval/labeled.jsonl # версия данных (git blob)
sha256sum eval/labeled.jsonl          # то же, sha256 (Windows: certutil -hashfile eval\labeled.jsonl SHA256)
python --version && pip freeze | grep -iE "torch|sentence|transformers|numpy"
```

Статусы: `planned` (записан, не прогонялся), `running`, `done`, `awaiting data` (код готов, ждём прогона или данных), `superseded by EXP-NNN`.
