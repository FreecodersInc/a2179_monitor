## 1. Источники (T-037)
robots и условия, проверено 2026-11-20 с dev машины (не заблокирована, раннер не понадобился):
* Arbeitnow `/api/job-board-api`: robots разрешает всё, API бесплатный без ключа, условие «не злоупотреблять, ссылка на сайт». Одна страница (300 новых) в день, кэш 24 ч.
* We Work Remotely RSS `remote-programming-jobs.rss`: robots разрешает `/`, закрыты только аккаунты и админка. Один фид в день.
* HN «Ask HN: Who is hiring?»: поисковый API HN (hn.algolia.com, robots.txt нет, 404). Два вызова в день: последняя ветка аккаунта whoishiring, потом её комментарии. Берём только комментарии верхнего уровня, ник автора не храним.

Живой прогон: Arbeitnow 300 (295 после дедупа), WWR 25, HN 239 (ветка за ноябрь 2026, 242 комментария верхнего уровня, 3 короче 8 символов отброшены). Всего с ATS, Remotive и Remote OK 3855 вакансий.

Минус: в верхних 10 по `score` из новых источников только 1 (WWR), в верхних 100 их 6 (Arbeitnow 4, WWR 1, HN 1). Arbeitnow в основном немецкие вакансии вне DE, HN без структуры, заголовок это первая строка комментария.

## 2. Переразметка старых 462 по полному тексту (T-032)
Покрытие: полный текст нашёлся для **462 из 462** (кэш ответов ATS, Remote OK и Remotive того же сбора, сопоставление по id вакансии в ссылке). Переразмечено **120 из 462**: случайно по 30 на каждую старую метку E, S, C, I (seed 20261120), разметчик тот же (бот), старую метку при разметке не видел, читал заголовок, компанию, термины стека из текста и абзац про обязанности. Поле `esci_text` в `labeled.jsonl`, у остальных 342 его нет.

| старая метка | меняется |
|---|---|
| E | 0 из 30 |
| S | 9 из 30 (C 5, I 3, E 1) |
| C | 19 из 30 (I 9, S 10) |
| I | 2 из 30 (S 2) |
| всего | **30 из 120, 0.25 (bootstrap 95% 0.175…0.325)** |

Бинарно (E или S против C или I) меняется 20 из 120. Похоже на EXP-011 (42 из 150, 0.28). Страты взяты поровну, поэтому 0.25 это не доля по всему набору, с весами старого состава (E 91, S 122, C 83, I 166) оценка по набору 0.22 (9/30·122 + 19/30·83 + 2/30·166 ≈ 100 из 462). Ограничение: тот же разметчик, без второго мнения.
