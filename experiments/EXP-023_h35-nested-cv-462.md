## Вопрос и гипотеза (до прогона)
На 462 AUC cv_score 0.880, на свежих 150 0.656 (EXP-011, EXP-020). Это переобучение числовых настроек профиля или другой состав свежей пачки?

**H-44.** Если числа профиля подбирать только на train фолдах, held out AUC на 462 ≥ 0.85, то есть 0.880 держится не на подгонке чисел. Опровержение: < 0.80, тогда 0.880 в основном подгонка.

**Проверка состава (заявлена до прогона).** Свежая пачка набрана по стратам правил на заголовке (match и rest по 75), в ней много C (68 из 150). Если AUC на 462 внутри страты match ≤ 0.75 и близка к batch3 внутри match (разница ≤ 0.05), разрыв объясняется составом, а не переобучением.

## Условия и установка
* Что подбирается внутри фолда: веса четырёх частей cv_score (skills, stack, domain, seniority) на симплексе шаг 0.1 (286 вариантов), шкала домена (значение для каждого класса правил = доля позитивов этого класса на train со сглаживанием 1/2), насыщение стека из {5, 10, 15, 20}. Выбор по AUC на train.
* Что не подбирается и остаётся утечкой: сами правила классов, список обязательных навыков и список стека писались, когда эти строки уже были видны. Эту часть вложенная CV не снимает, её снимает только свежая пачка, поэтому отдельно: настройка на всех 462, проверка на batch3.
* Внешний цикл 5 фолдов, стратификация по позитиву, 10 повторов. AUC на test пулом по фолдам, среднее по повторам. Рядом ручной профиль (как в EXP-020) на тех же фолдах.
* Позитив: E или S по `esci_text`.

## Что прочитано и как это повлияло
* **Varma, Simon 2006, Bias in error estimation when using cross-validation for model selection** ([BMC Bioinformatics 7:91](https://doi.org/10.1186/1471-2105-7-91)): оценка CV для классификатора, чьи параметры подобраны той же CV, заметно смещена вверх, на «пустых» данных давала ошибку < 30% там, где на независимых данных был уровень случайности. Вложенная CV, где подбор повторяется в каждом внешнем фолде, даёт почти несмещённую оценку. Отсюда правило: весь подбор чисел внутри фолда, и отдельная независимая проверка на batch3 для той части, которую повторить внутри фолда нельзя (ручные правила).
