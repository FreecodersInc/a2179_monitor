## Цель
Проверить, что пайплайн (профиль цели, сбор, разметка, eval, свип, CI) переносится на совсем другой домен, язык и источники: поток вакансий вместо объявлений о запчастях. Цель «вакансия, на которую Лёне есть смысл откликаться как Data Engineer». Это вторая цель для M-001 (T-003) и полигон для H-02, H-03, H-28, H-29, H-30, H-31.

Почему кейс хороший: та же беда «тема против цели». Пример, проверенный 2026-11-19: публичный API Remotive с `category=data` вернул 15 вакансий, из них Data Engineer одна, остальное full stack, саппорт, копирайтинг. Ровно наш «та же тема, не то».

## Форма профиля (`targets/de_jobs.json`, без личных данных)
- `rules.models` вместо моделей ноутбука: роль. Сильные титулы (data engineer, analytics engineer, инженер данных, inženjer podataka), слабые (data platform, big data developer, ETL developer) с условием на навыки
- `family` и `conflict`: data scientist, ML engineer, data analyst, BI developer как соседи по теме (трудные негативы), не как цель
- навыки как группы признаков с весом (аналог `F_DISPLAY` и `F_OTHER`): обязательные (SQL, Python или Scala, один из Spark / Flink / dbt / Airflow), плюсы (облако, Kafka, lakehouse), минусы (только Excel, только BI отчёты)
- seniority: junior / middle / senior / lead как атрибут из титула и опыта в годах
- локация и формат: remote, hybrid, город, часовые пояса, «EU only», «US only» как жёсткое исключение
- языки вакансии и требований: английский, сербский (латиница и кириллица), немецкий. Нормализация как сейчас плюс язык как атрибут
- зарплата: вилка и валюта, если указана, минимальный порог как `target_price` наоборот (нижняя граница)
- намерение: вакансия / агентство / курс или буткемп / «ищу работу» (резюме) как группы исключений
- прототипы: 15 на сторону, написаны руками, без текста CV

## Источники (только публичные страницы списков или официальные API и RSS)
Проверено 2026-11-19, все отвечают 200. Перед кодом каждого источника читаем ToS и robots.txt и пишем вывод в задачу.

| источник | как | язык | условия |
|---|---|---|---|
| Remotive | официальный JSON API `remotive.com/api/remote-jobs` | en | в ответе legal notice: ссылка назад и упоминание Remotive, не перепубликовывать на сторонних сайтах, не чаще 4 запросов в день, вакансии с задержкой 24 часа |
| Remote OK | официальный JSON API `remoteok.com/api` | en | ToS в ответе: ссылка назад и упоминание Remote OK |
| Arbeitnow | официальный JSON API `arbeitnow.com/api/job-board-api` | en, de | документация в их блоге, ToS прочитать до кода |
| We Work Remotely | RSS по категориям | en | RSS публичный, ToS прочитать |
| Hacker News «Who is hiring» | официальный HN API (Firebase) и Algolia HN Search API | en | публичные API, комментарии людей, только чтение |
| HelloWorld.rs | публичные страницы `oglasi-za-posao` | sr | robots.txt не запрещает списки, ToS прочитать до кода |
| Infostud (poslovi.infostud.com) | только если ToS разрешает | sr | robots.txt запрещает `/?*`, `/search/*` и `/rss_feed/*`, то есть поиск с параметрами и RSS нельзя. Пока не берём |
| LinkedIn, Indeed, Glassdoor | не берём | | ToS запрещает автоматический сбор |

Ничего не деплоится, никаких откликов и сообщений работодателям. Сбор руками у Лёни или в CI раз в сутки, с тем же общим лимитером, что и KP. Вакансии в `eval/` только как заголовок, короткий фрагмент, ссылка и источник, без перепубликации.

## Разметка
- `eval/enrich.py` с профилем `de_jobs`: авто метки правилами (титул, навыки, seniority, локация), `reason`, ревью Лёней (он единственный, кто знает, куда ему откликаться)
- метки 4 класса по ESCI (H-27): подходит / подходит с натяжкой (соседняя роль или seniority) / тот же домен, не то (DS, аналитик) / мимо
- 300 строк на старт, половина трудные негативы (соседние роли), минимум 50 на сербском
- согласие: 50 строк вторым разметчиком (H-07)

## Для чего CV
- только чтобы Лёня и агент вместе вытащили из него список навыков, seniority, языков и предпочтений по локации. Этот список Лёня утверждает, и только он попадает в `targets/de_jobs.json`
- сам CV не коммитится: репо публичный. CV лежит у Лёни локально в `private/` (папка в `.gitignore`), или у агента вне репо, и удаляется по просьбе
- в профиле нет имени, контактов, работодателей, дат, ничего, что идентифицирует человека
