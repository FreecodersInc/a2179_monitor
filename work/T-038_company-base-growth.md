## Цель
Узкое место не модель, а входная воронка: из 608 матчей под удалёнку из Сербии живыми осталось 22. Нужна база в несколько сотен живых ATS бордов (дальше к тысяче), которую монитор опрашивает и на экран, и на вакансии. Наш алгоритм работает фильтром, прошедшее падает алертом в телегу (алерты включаются при запуске у Лёни, не в CI).

## Критерии приёмки
- [ ] `data/companies.csv` с полями: имя, домен, ATS, слаг, источник, гео подсказка, дата последней удачной проверки, число вакансий. Дубли режем по домену
- [ ] первый заход: несколько сотен живых бордов (ответ 200 со списком вакансий)
- [ ] проба слага по публичным API Greenhouse, Lever, Ashby и Workable, с тестом на фикстурах
- [ ] отдельный адаптер для своего сайта карьеры без ATS, первым JetBrains
- [ ] контрольный тест гео фильтра: свежие вакансии JetBrains в Белграде проходят фильтр без отдельных поблажек. Не прошли, значит фильтр косячит
- [ ] CI раз в сутки проверяет все борды, отчёт: живые борды, стянуто вакансий, прошло фильтр, где отвалилось

## План
1. Откуда брать компании
   - GitHub списки remote контор, например remoteintech/remote-jobs (сотни компаний с пометкой про гео)
   - каталог YC с фильтрами remote и hiring, плюс Wellfound
   - Himalayas, Remotive, We Work Remotely: страницы компаний, гео уже вшит
   - белградские работодатели с местных площадок типа HelloWorld.rs и Startit
   - обратный ход: поиск по boards.greenhouse.io, jobs.lever.co, jobs.ashbyhq.com со словами Serbia, Belgrade, EMEA, Europe remote. Каждый найденный борд сразу готовый слаг
   - для каждого источника сначала robots и условия, как в T-018
2. Компания в живой борд: для каждого имени генерим варианты слага (слитно, через дефис, без Inc и Ltd) и стучимся в публичные API
   - `https://boards-api.greenhouse.io/v1/boards/SLUG/jobs`
   - `https://api.lever.co/v0/postings/SLUG?mode=json`
   - `https://api.ashbyhq.com/posting-api/job-board/SLUG`
   - Workable по тому же принципу
   - ответ 200 со списком вакансий значит борд живой, пишем в базу
3. База `data/companies.csv` (поля выше), у кого свой сайт карьеры без ATS, тому отдельный адаптер
4. CI под эксперименты: раз в сутки крон проверяет все борды, три фейла подряд и борд в спячку. Рост базы сам по себе метрика
5. Приоритеты: компании, у которых хоть раз вакансия прошла гео фильтр, проверяем чаще, пустые и чисто американские реже
