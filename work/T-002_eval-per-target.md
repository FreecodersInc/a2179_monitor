## Цель
`eval/run_eval.py`, `eval/sweep.py`, `eval/enrich.py` берут цель из профиля: путь к набору, запросы сбора (сейчас 43 запроса A2179 в `enrich.py`), группы признаков (`F_DISPLAY`, `F_OTHER` в `sweep.py`), `kind` значения.

## Критерии приёмки
- [ ] секция `eval` в профиле: `data`, `queries`, `features`, `kinds`
- [ ] `--target` у всех трёх скриптов, по умолчанию из конфига
- [ ] для A2179 те же числа в `reports/`, тесты зелёные
- [ ] наборы по цели: `eval/<target>/labeled.jsonl` (A2179 с переносом и тем же blob)
