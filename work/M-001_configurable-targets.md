## Цель
Любую цель (деталь, товар, документ) можно поставить профилем в `targets/` и прогнать весь цикл: монитор, сбор кандидатов, разметка, eval, свип, CI. Нужно для гипотез H-02, H-03, H-09 (experiments/HYPOTHESES.md). Решение: ADR-0010.

## Критерии готовности
- [x] правила, прототипы, источники, цена цели, пороги монитора в профиле, A2179 без изменений (T-001)
- [ ] eval сторона читает цель из профиля: набор, запросы сбора, группы признаков (T-002)
- [ ] вторая реальная цель с профилем и ≥ 200 размеченными строками (T-003)
- [ ] CI гоняет eval и свип для каждой цели и пишет метрики по цели в результат (T-004)
- [ ] тексты уведомлений и валюта по профилю, а не по Сербии (T-005)
