## Цель
По ADR-0017 этот замер на вакансиях идёт параллельно с тем же сравнением на `targets/a2179_screen.json` (T-016), а не после всех гипотез на одном кейсе.

Тот же вопрос, что T-016, на другом языке и домене: нужен ли эмбеддер, если есть правила и атрибуты.

Сравнение с A2179 само по себе не есть вывод про язык: вместе меняются язык и домен. Чистый эффект языка смотрим в T-022 (перевод тех же сербских лотов на английский, один эмбеддер на обоих).

## Критерии приёмки
- [ ] модели из `eval/embedders.json` на вакансиях (английский, сербский)
- [ ] no ML база: правила + атрибуты + очередь спорных (H-31)
- [ ] вывод, совпадает ли ответ с A2179
