## Цель
Таблица P@R1, nDCG@npos по 5 моделям на одном наборе, CUDA и CPU сверены, ранги сравнены с MTEB.

## Критерии приёмки
- [ ] `sweep.py --model` для каждой модели, оценки в `dense_scores_<model>.jsonl`
- [ ] префиксы `query:` / `passage:` для E5 как параметр, с ними и без
- [ ] max ∣Δcos∣ CUDA против CPU (H-11)
- [ ] Spearman рангов против MTEB (H-28)

## План
1. Скопировать гипотезы (H-01, H-11, H-17, H-23, H-28) дословно в новую EXP запись до прогона.
2. Код как параметр `eval/sweep.py` или отдельный канал, тест на маленьком примере.
3. Прогон в CI на раннере, числа из `results/<base>.json` и графики из `results/<base>/`.
4. Статусы гипотез в `experiments/HYPOTHESES.md`, решение в ADR, если что-то меняем в мониторе.
