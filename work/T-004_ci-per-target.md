## Цель
`ci/run_experiments.py` гоняет eval и свип для каждого профиля из `targets/` (или из переменной `A2179_CI_TARGETS`), результат содержит метрики по цели.

## Критерии приёмки
- [ ] `metrics.<target>.eval` и `.sweep` в `results/*.json` (schema 3)
- [ ] без правки YAML
- [ ] тест на два профиля

## Ссылки
- решения: ADR-0009, ADR-0010

## Заметки и итог
CI уже пишет отчёты ручной проверки по обоим публичным профилям (`eval/review_run.py`, шаг `review`). Eval и свип с метриками `metrics.<target>.eval` по-прежнему только для A2179, пока нет размеченного набора вакансий (T-019).
